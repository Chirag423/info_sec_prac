## Practical 1 – Network Tools (Theory)

| Tool | Purpose |
|------|---------|
| `ping` | Tests reachability of a host; measures round-trip time |
| `ipconfig` / `ifconfig` | Displays IP configuration of network interfaces (Windows / Linux) |
| `tracert` / `traceroute` | Shows the hop-by-hop path packets take to a destination |
| `arp` | Displays and modifies the ARP cache (IP ↔ MAC mapping) |
| `netstat` | Shows active connections, listening ports, routing tables |
| `whois` | Queries domain/IP registration information |

See theory explanation provided separately.
